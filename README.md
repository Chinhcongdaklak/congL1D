# Kho phat hanh LVC LD Manager

Kho nay chi dung de **phat hanh ban moi**. Ma nguon khong nam o day.

## Nguoi dung tai ban moi the nao

1. Mo tool len - neu co ban moi, goc tren ben phai hien nut vang
   **Co ban moi ... - Cap nhat**. Bam vao la xong.
2. Hoac bam `LVCLDUpdate.exe` nam canh tool.
3. Hoac tai tay tai **[Releases](../../releases/latest)**.

## Dat tool o dau

De `LVC LD Manager.exe` va `LVCLDUpdate.exe` cung mot thu muc, canh hai thu muc
`data\` (acc, cai dat, selector) va `app\` (facebook.apk). Hai thu muc nay KHONG
nam trong .exe va KHONG bi ban cap nhat ghi de.

## Vi sao file .exe nam trong Releases chu khong nam trong kho

Moi ban .exe vai chuc MB; giu trong Releases de kho ma khong phinh ra.
Tep dinh kem trong Releases cho toi 2 GB.
